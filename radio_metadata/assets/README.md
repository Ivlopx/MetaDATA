# Iconos de identificación de fuentes

Recursos originales, sin redibujar ni recolorear. Las marcas pertenecen a sus respectivos titulares; su presencia identifica conectores y no implica patrocinio.

- RadioBOSS y RadioCaster: https://www.djsoft.net/enu/download.htm — archivos https://www.djsoft.net/images/icons/radioboss_icon.png y https://www.djsoft.net/images/icons/radiocaster_icon.png.
- Spotify: https://developer.spotify.com/documentation/design — archivo https://developer-assets.spotifycdn.com/images/guidelines/design/icon1.svg. El PNG incluido se extrae sin modificaciones del recurso original embebido en ese SVG, para compatibilidad con el renderizador Qt. Se muestra junto al nombre Spotify, en el espacio limitado del selector y las conexiones.

Los otros conectores utilizan iconos genéricos de Qt. Los puntos de estado son símbolos nativos acompañados de texto.
